# DuckDuckGo Browser

A lightweight, single-page DuckDuckGo search start page.

## Run locally

Open `index.html` in a browser, or serve this folder with a local web server:

```sh
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

Searches open DuckDuckGo results in a new tab because DuckDuckGo does not allow its search site to be embedded in an iframe.
